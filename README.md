# YG Easy Extension

YG Easy - расширение для быстрого создания иерархических задач в YouGile.

Проект помогает собирать "матрёшки" задач: родительскую задачу, подзадачи, стикеры, исполнителей, дедлайны, шаблоны и справочники YouGile в одном интерфейсе.

## Возможности

- Быстрая версия popup для создания родительской задачи или родительской задачи с одной подзадачей.
- Полноэкранный конструктор дерева задач с произвольной иерархией.
- Синхронизация справочников YouGile: проекты, доски, колонки, пользователи и стикеры.
- Поиск в выпадающих списках.
- Автоматическое добавление доски в название задачи.
- Автоматическое сопоставление стикера `Проект` по названию доски.
- Поддержка стикеров, дедлайнов, даты старта, исполнителей и описаний.
- Импорт и экспорт шаблонов задач в читаемом JSON-формате.
- Раздел настроек для готового API-ключа и запроса/отслеживания токенов.

## Установка предрелизной версии

1. Скачайте ZIP-архив из раздела предрелиза.
2. Распакуйте архив в удобную папку.
3. Откройте страницу расширений:
   - Chrome: `chrome://extensions`
   - Opera: `opera://extensions`
   - Яндекс Браузер: `browser://extensions`
4. Включите режим разработчика.
5. Нажмите `Загрузить распакованное расширение`.
6. Выберите папку `YG-Easy-extension` из распакованного архива.
7. Откройте расширение, перейдите в `Настройки` и вставьте API-ключ YouGile.

Важно: предрелизная версия устанавливается как распакованное расширение. Браузер может показывать предупреждение о режиме разработчика.

## Локальная разработка

Установить зависимости:

```bash
npm install
```

Запустить web-режим для разработки:

```bash
npm run dev:web
```

Собрать расширение:

```bash
npm run build:extension
```

После сборки готовые файлы расширения находятся в папке `dist`.

## Проверки

Запустить тесты:

```bash
npm test
```

Проверка TypeScript выполняется внутри команды сборки:

```bash
npm run build:extension
```

## Безопасность

Не коммитьте реальные API-ключи и локальные токены. Файл `local-yougile-token.txt`, папки `dist`, `release`, `node_modules` и логи исключены через `.gitignore`.
