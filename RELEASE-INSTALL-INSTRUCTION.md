# YG Easy: установка расширения

1. Распакуйте архив в удобную папку.
2. Откройте страницу расширений:
   - Chrome: `chrome://extensions`
   - Opera: `opera://extensions`
   - Яндекс Браузер: `browser://extensions`
3. Включите режим разработчика.
4. Нажмите `Загрузить распакованное расширение`.
5. Выберите папку `YG-Easy-extension` из распакованного архива.
6. Откройте расширение, перейдите в `Настройки` и вставьте API-ключ YouGile.

Важно: это dev-сборка для ручной установки. Браузер может показывать предупреждение о режиме разработчика.
