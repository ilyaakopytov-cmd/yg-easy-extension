# YG Easy integration checklist

## Цель

Проверить установленное unpacked extension из папки `dist` на реальном тестовом YouGile.

## Подготовка

1. Выполнить сборку:

```bash
npm run build:extension
```

2. Открыть Chrome:

```text
chrome://extensions
```

3. Включить Developer mode.
4. Нажать Load unpacked.
5. Выбрать папку:

```text
C:\Users\Theobald\Desktop\yg-easy-extension\dist
```

## Настройки API-ключа

1. Открыть Options page расширения.
2. Вставить API-ключ YouGile.
3. Оставить session-режим, если не нужно сохранять ключ локально.
4. Нажать проверку подключения.
5. Убедиться, что количество проектов вернулось без ошибки.

Нельзя копировать API-ключ в логи, issue, скриншоты или этот файл.

## Справочники

1. Открыть fullpage расширения.
2. Нажать "Обновить из YouGile".
3. Проверить, что появились:
   - проекты;
   - доски;
   - колонки;
   - пользователи;
   - стикеры.
4. Проверить, что дата последнего обновления стала текущей.

## Проверка одиночной задачи

1. В fullpage оставить только root-задачу.
2. Заполнить:
   - проект;
   - доску;
   - колонку;
   - название;
   - описание.
3. Нажать "Создать задачи".
4. Проверить в YouGile:
   - задача появилась в выбранной колонке;
   - в payload/result у root есть `yougileTaskId`;
   - ошибок нет.

## Проверка двухуровневой матрешки

1. В popup или fullpage создать дерево:

```text
Root
└ Child
```

2. Нажать "Создать задачи".
3. Проверить в YouGile:
   - в колонке виден только root;
   - child виден внутри root как подзадача;
   - child не отображается отдельной карточкой в колонке.

## Проверка трехуровневой матрешки

1. В fullpage создать дерево:

```text
Root
└ Child
  └ Leaf
```

2. Нажать "Создать задачи".
3. Проверить:
   - в колонке виден только root;
   - child внутри root;
   - leaf внутри child;
   - columnId был только у root.

## Проверка ветвистой матрешки

1. В fullpage создать дерево:

```text
Root
├ Child A
│ └ A1
└ Child B
  └ B1
```

2. Нажать "Создать задачи".
3. Проверить:
   - в колонке виден только root;
   - обе ветки находятся внутри root;
   - вложенные задачи не появились отдельными карточками.

## Проверка стикеров

1. Создать задачу со state-стикером.
2. Создать задачу с numeric-стикером.
3. Создать root с чекбоксом "Родитель".
4. Проверить в YouGile, что значения применились.

## Проверка частичного сбоя и повтора

1. Создать дерево из нескольких задач.
2. Спровоцировать ошибку после создания части задач, например временно указать неверный sticker/state на одной из нижних задач.
3. Проверить, что UI показывает:
   - создано N;
   - ошибок M;
   - localId;
   - title;
   - status;
   - yougileTaskId;
   - error.
4. Исправить ошибку.
5. Нажать "Повторить неуспешные".
6. Проверить, что задачи с уже заполненным `yougileTaskId` не создались повторно.

## Критерий успеха блока 14

- API-ключ проверен в extension-режиме.
- Справочники обновлены из YouGile.
- Создана одиночная задача.
- Создана двухуровневая матрешка.
- Создана трехуровневая матрешка.
- Создана ветвистая матрешка.
- Подзадачи не появляются отдельными карточками в колонке.
- `columnId` есть только у root-задачи.
- API-ключ не отображается в UI-логах и результатах.
