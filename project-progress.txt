YG Easy - отчет по блокам работ
Дата: 13.05.2026

Исходное ТЗ:
Браузерное расширение YG Easy для быстрой постановки иерархических задач в YouGile через YouGile REST API v2. Основная механика: пользователь собирает дерево задач, расширение создает матрешку снизу вверх, все вложенные задачи создаются без columnId, только верхняя root-задача создается с columnId выбранной колонки.
